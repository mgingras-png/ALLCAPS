# ALLCAPS
iPod Classic Theme with Large Fonts

Version 1.0

Last Update: 08/17/2026

License: CC-BY-SA 3.0

By: Monica G.

Description: All capital letters for the font and large text size for the title and artist. I merged the fonts Home Video by GGBOTNET and LanaPixel by eishiya using FontForge. Other than that, pretty simple theme! Code is based on my previous themes, specifically bunnyPod and minimal_RTCsync. All icons created by me.


## fonts
- HomeVideo-CJK
    - made with Font Forge using:
        - LanaPixel
        - Home Video
